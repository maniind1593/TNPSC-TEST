இரண்டு பேரும் தனித்தனி மொபைலில் Login இல்லாமல் ஒரே நேரத்தில் தேர்வு எழுதலாம்.

தேர்வில் இணையவும்

உங்களுக்கு விருப்பமான Test Code-ஐ மாற்றி (அல்லது புதிய Code உருவாக்கி) நண்பருடன் பகிர்ந்து கொள்ளுங்கள்.

நண்பருக்குச் சொல்ல வேண்டிய Code: -
பதிலளித்தவை: 0 / 10

உங்கள் தேர்வு சமர்ப்பிக்கப்பட்டது!

உங்கள் நண்பரும் தேர்வை முடிக்கும் வரை முடிவுகள் மறைக்கப்பட்டிருக்கும். அவர் Submit செய்த நொடியில் முடிவுகள் இங்கே தானாகத் தோன்றும்.

இருவரின் தேர்வு முடிவுகள்

Admin View — High & Low Score

தேர்வு முடிந்த பிறகு Test Code மற்றும் Admin PIN கொடுத்து யார் அதிக மதிப்பெண் (High), யார் குறைந்த மதிப்பெண் (Low) என்பதைப் பார்க்கவும்.

குறிப்பு: ஒரு Test Code-க்கு இரண்டு பங்கேற்பாளர்கள் மட்டுமே அனுமதிக்கப்படுவர்.
